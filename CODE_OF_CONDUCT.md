# Code of Conduct

## Our standard

Everyone participating in this project is expected to help make its community respectful, constructive, and welcoming to people with different backgrounds and experience levels.

Examples of behavior that supports this standard include:

- Being considerate and respectful in discussions and reviews.
- Giving and receiving technical feedback constructively.
- Focusing criticism on code and ideas, not people.
- Respecting differing viewpoints and experiences.

Unacceptable behavior includes harassment, discriminatory language, personal attacks, and deliberate disruption of project discussions.

## Reporting

Report conduct concerns to the project maintainers through the repository's contact options: https://github.com/DeveloperRejaul/react-native-rust. Maintainers will review reports and take appropriate action.

## Scope

This policy applies in project issues, pull requests, discussions, and other spaces used for project participation.
